# Security Policy

## Scope

Codex Dispatch connects external task inputs with a user's local development environment. Security and safety boundaries are a core design goal.

## Principles

- Never commit secrets or authentication tokens.
- Never derive executable paths directly from user text.
- Validate all selected projects against discovered local projects.
- Keep dangerous operations explicit.
- Prefer reversible local changes.

## Reporting

Security reporting instructions will be added before public release.
